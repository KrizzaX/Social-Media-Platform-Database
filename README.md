# Social Media Platform Database

## Overview

This project is a relational database designed for a social media platform. The database stores and connects information about users, posts, comments, likes, messages, friendships, groups, follows, and notifications.

The project was created to practice designing a database system and using SQL to organize, connect, and retrieve data.

## Database Features

The database includes tables for:

* Users and profiles
* Posts, comments, and likes
* Messages and chats
* Friendships and follows
* Groups and group memberships
* Notifications

Relationships between the tables are created using primary and foreign keys.

## SQL Queries

The project includes queries for tasks such as:

* Retrieving a user's profile
* Finding posts created by a user
* Viewing comments and likes on posts
* Finding a user's friends
* Retrieving messages and notifications
* Listing members of a group
* Finding popular posts based on likes
* Filtering posts by visibility

## Technologies

* SQL
* MariaDB
* Relational Database Design

## Files

* `tables.sql` - Creates the database tables and relationships
* `data.sql` - Adds sample data to the database
* `queries.sql` - Contains example queries for retrieving and analyzing data
